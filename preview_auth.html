공유기 포트포워딩이나 복잡한 IP 입력, 6자리 룸코드를 매번 주고받을 필요가 없습니다. 평소 사용하시던 Google 계정으로 단 1번만 로그인하면, 집이나 연구실에 켜둔 모든 Windows 호스트 PC가 클라우드에 자동 등록되어 언제 어디서나 초저지연 120Hz 스트림에 즉시 접속할 수 있습니다.

ALL 4 PLATFORMS FULLY INTEGRATED

전체 프로그램(Windows 데스크톱 앱, Android, iOS, Web) 로그인 기능 탑재 완료

대표이사님 지침에 따라 주식회사 제로독의 모든 클라이언트 및 호스트 프로그램에 단일 Google 계정 기반의 클라우드 인증 및 자동 기기 페어링 엔진이 탑재되었습니다.

SINGLE SIGN-ON READY: 4/4
HOST CORE ENGINE · RUST & NVENC

Windows 호스트 서버 (`aether-server.exe`) 구글 인증 시스템

OAuth 2.0 Loopback Inno Setup 2.58MB
01. 트레이 아이콘 원클릭 구글 로그인

Windows 작업 표시줄 트레이에서 [Sign in with Google] 클릭 시 로컬 루프백 브라우저를 통해 0.1초 만에 보안 토큰을 발급받아 호스트를 자동 등록합니다.

02. 내 PC 클라우드 레지스트리 자동 갱신

호스트의 LAN IP, STUN 공인 IP, 활성 GPU(RTX 4090/4070 등), 인코더 상태(NVENC 초저지연 하드웨어 인코딩)를 계정에 실시간 동기화하여 태블릿 클라이언트에 즉시 노출합니다.

03. Google Drive 자동 빌드 미러링 연동

로그인된 구글 드라이브(G:\ 또는 H:\ 드라이브) 경로와 감시 루틴을 연결하여, 신규 빌드본 생성 시 외부 기기 배포 폴더로 자동 복제합니다.

ANDROID NATIVE CLIENT · KOTLIN & JETPACK COMPOSE

Android 클라이언트 Google Sign-In & 144Hz 호스트 피커

01. Google One-Tap 네이티브 로그인

기기에 로그인된 Google 계정을 원탭으로 연동하여 별도 ID/PW 입력 없이 즉시 로그인 완료. Neo-Brutalist 커스텀 프로필 카드를 렌더링합니다.

02. 내 호스트 기기 라이브 카드 피커

Windows 호스트가 전송한 실시간 텔레메트리(초저지연 핑, 144Hz 대역, 온라인 상태)를 Jetpack Compose LazyColumn으로 즉각 표시하고 탭 한 번으로 스트림을 시작합니다.

03. S-Pen 4096 필압 백업 프로필 로드

구글 계정에 저장된 클라우드 펜 압력 곡선 매핑과 핫키 프로필을 자동으로 복원하여 타블렛 작업 시 즉각적인 필기감을 제공합니다.

IOS CLIENT · SWIFT & APPLE METAL 3

iPad / iPhone iOS Google Sign-In & 120Hz ProMotion 스트리밍

01. 애플 보안 가이드라인 준수 구글 인증

iOS 네이티브 ASWebAuthenticationSession과 Google Sign-In SDK를 연동하여 Keychain에 JWT 보안 토큰을 제로트러스트로 보관합니다.

02. iPad Pro 120Hz ProMotion 제로레이턴시

구글 계정으로 연결된 내 호스트 PC를 터치하는 즉시 VideoToolbox 하드웨어 디코더와 Apple Metal 3 셰이더 파이프라인이 구동됩니다.

03. Apple Pencil Pro 틸트/압력 프로필 동기화

구글 드라이브와 연계된 브러시 설정이 호스트 PC의 가상 디지타이저 드라이버로 즉각 주입되어 정밀한 드로잉을 지원합니다.

WEB CLIENT & DEEP LINK GATEWAY · HTML5 & JAVASCRIPT

공식 웹사이트 (`index.html` / `ko.html`) 및 웹 조인 (`join.html`) 구글 로그인 바

PKCE Web Auth Bilingual KR / EN
01. 글로벌 네비게이션 구글 로그인 & 드롭다운

영문 공식 사이트(index.html)와 한국어 사이트(ko.html) 상단 네비게이션에 통일된 [Sign in with Google] 버튼 및 프로필 관리 메뉴를 마운트했습니다.

02. 조인 게이트웨이 (`join.html`) 로그인 바 탑재

6자리 룸코드 입력창 바로 상단에 구글 로그인 바를 배치하여, 로그인 시 내 PC 목록이 즉시 표시되어 룸코드 없이 1클릭으로 바로 접속할 수 있습니다.

03. 브라우저 간 세션 동기화 (LocalStorage)

웹사이트 어느 페이지에서 로그인하더라도 전역 상태가 즉시 동기화되어 새로고침 없이 프로필과 호스트 목록이 연동됩니다.

AetherStream 구글 계정 연동 4대 핵심 기술 명세

주식회사 제로독의 비주얼 디자인 시스템(0px 직각, 솔리드 플랫)과 엔터프라이즈급 제로트러스트 보안 프로토콜을 결합하여 설계되었습니다.

01 / IDENTITY
OAuth 2.0 PKCE 인증
비밀번호를 저장하지 않는 RFC 7636 PKCE(Proof Key for Code Exchange) 기반 구글 단일 인증으로 브라우저 탈취 위험을 원천 차단합니다.
TOKEN: RS256 JWT / AUTO-REFRESH
02 / MULTI-HOST PAIRING
내 PC 자동 클라우드 레지스트리
Windows 호스트 인스톨러(`aether-server.exe`) 실행 시 동일 구글 계정으로 자동 페어링되며, 실시간 온라인 상태, GPU 모델, 지연시간을 갱신합니다.
Direct VRAM 초저지연 바인딩
03 / CLOUD BACKUP
Google Drive 빌드본 자동 동기화
신규 Windows 인스톨러 및 태블릿 클라이언트 빌드 시 로컬 구글 드라이브(`G:\내 드라이브\AetherStream_Builds`)와 실시간 자동 미러링됩니다.
DRIVE PATH: G:\ / H:\ AUTOMATION
04 / DESIGN SYSTEM
100% 0px 솔리드 플랫 네오 브루탈리즘
그라데이션(0%), 그림자(0%), 모서리 라운딩(0px)을 철저히 배제하고 순수 블랙(#000000)과 Pretendard 타이포그래피만으로 군더더기 없는 조작감을 완성했습니다.
