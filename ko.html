초저지연을 향한 타협 없는 엔지니어링.

기존의 오래된 CPU 버퍼 방식과 달리,
zerodoc AetherStream은 최신 DirectX 12, Apple Metal 3, 동적 UDP FEC 에러 복구를 하나로 결합했습니다.

Direct VRAM GPU 캡처

시스템 RAM 왕복을 최소화합니다. Direct3D 11 IDXGIOutputDuplication을 통해 GPU VRAM 텍스처를 하드웨어 인코딩 파이프라인으로 직접 연결하여 캡처 지연을 극적으로 줄입니다.

DXGI 1.2+ VRAM 직결

포트포워딩 없는 6자리 룸코드

회원가입, 이메일 인증, 공유기 포트포워딩이 전혀 필요 없습니다. 호스트 프로그램을 켜고 6자리 코드만 공유하면 친구나 보조 디바이스가 3초 안에 P2P 직결됩니다.

제로 마찰 P2P 직결

Apple Pencil 4096단계 필압 & 틸트

내 아이패드가 고가의 전문 액정 타블렛으로 변신합니다. 지브러시(ZBrush), 블렌더(Blender), 클립스튜디오, 포토샵에서 8ms 미만 지연시간으로 섬세한 드로잉을 지원합니다.

Windows Ink & Wintab 연동

4:4:4 크로마 & 10-bit HDR 무손실

뿌옇게 번지는 붉은 텍스트와 색상 계단 현상을 영원히 작별하세요. 서브픽셀 무손실 렌더링으로 VS Code 코딩, 다빈치 리졸브 영상 편집, 고품질 게임 그래픽을 왜곡 없이 표현합니다.

풀 RGB 트루컬러

DXGI 1.2+ 제로카피 데스크톱 캡처

Windows DXGI 1.2+ Desktop Duplication API를 통해 GPU VRAM에서 직접 활성 화면을 캡처합니다. 다중 모니터 환경에서도 성능 저하 없이 원하는 활성 디스플레이를 즉시 전환하여 스트리밍합니다.

GPU 제로카피 캡처

4인 로컬 파티플레이 코옵 & ViGEm

전 세계 어디에 있는 친구와도 한 방에서 게임하듯 로컬 멀티플레이를 즐기세요. 호스트 PC가 ViGEmBus를 통해 4개의 가상 엑스박스 360 / 듀얼쇼크 4 컨트롤러를 자동 에뮬레이션합니다.

초저지터 파티플레이

100% 방화벽 우회 글로벌 TURN 메쉬

기숙사 Wi-Fi, 엄격한 기업 사내망, 호텔 방화벽은 일반 UDP 포트를 차단합니다. 전 세계 38개 엣지 노드로 구성된 TURN 메쉬가 대칭형 NAT를 통과시키며 TLS 폴백을 지원합니다.

AetherStream은 Apple Pencil Pro의 압력과 기울기를 초저지터 UDP를 통해 Windows Ink 및 Wintab API로 1:1 직결합니다.

01

4096단계 정밀 필압 & 틸트(기울기) 지원

ZBrush에서 유기적인 3D 스컬프팅을 하거나 클립스튜디오에서 수채화 브러시의 필압 번짐을 8ms 미만의 극초저지연으로 제어합니다.

02

애플 펜슬 호버 감지 & 더블 탭 제스처

펜촉이 화면에 닿기 전 커서 위치가 윈도우 마우스 좌표와 오차 없이 일치하며, 펜슬 본체 더블 탭으로 브러시/지우개 도구를 즉시 전환합니다.

03

아이패드 4:3 맞춤 해상도 자동 생성

호스트 PC의 GPU가 아이패드 고유의 4:3 및 3:2 화면비에 맞는 120Hz 가상 캔버스를 자동 생성하여 레터박스(검은 여백) 없이 꽉 찬 화면을 제공합니다.

기존 일반 P2P 솔루션은 단순 포트 바인딩에 의존하므로, 공유기 방화벽이나 학교/기숙사처럼 대칭형 NAT(Symmetric NAT) 환경에서는 외부 접속이 차단됩니다. 이를 우회하려면 복잡한 가상 사설망(VPN)을 별도로 구축해야 하는 번거로움이 있습니다.

zerodoc AetherStream은 RFC 5389 STUN NAT 홀펀칭을 우선 시도하고, 차단된 환경에서는 전 세계 38개 고속 TURN 엣지 릴레이 노드가 표준 HTTPS 포트(443)를 통해 암호화된 UDP 패킷을 자동 중계하므로 전 세계 어디서든 무조건 연결됩니다.

iOS 환경에서 Apple Pencil 터치는 초당 240Hz로 정밀 샘플링됩니다. AetherStream은 4096레벨 필압과 틸트(기울기), 펜 좌표를 초경량 16바이트 UDP 패킷으로 압축하여 즉시 송출합니다.

윈도우 호스트 PC에서는 일반 마우스 큐를 우회하여 Windows Ink 디지타이저 서브시스템 및 Wintab API로 다이렉트 인젝션하므로, 입력 지연이 8ms 미만으로 유지되어 실제 와콤 타블렛을 쓰는 것과 동일한 반응성을 느낄 수 있습니다.

AetherStream은 Windows 네이티브 DXGI 1.2+ Desktop Duplication API를 사용하여 CPU 메모리 복사 없이 GPU VRAM에서 직접 활성 화면을 캡처합니다.

연결된 모든 물리 디스플레이를 정확하게 감지하며, 클라이언트에서 원하는 모니터를 즉시 선택 및 전환하여 하드웨어 가속 비트스트림으로 스트리밍할 수 있습니다.

네, 100% 영구 무료입니다. 동일 네트워크 및 일반 P2P 환경에서의 1080p 120Hz 스트리밍, 6자리 룸코드 접속, 2인 게임패드 코옵은 클라우드 중계 서버 비용이 들지 않으므로 절대로 유료화하지 않습니다.

Pro 유료 구독은 글로벌 38개 전용 TURN 중계 서버 유지비와 Apple Pencil 전문 드로잉 도구, 다중 모니터 제로카피 전환 등 전문가용 고성능 기능을 지원하기 위한 합리적인 요금제입니다.

네, 완벽하게 지원합니다. 호스트 PC에 내장된 ViGEmBus 가상 드라이버가 최대 4대의 모바일 기기(아이폰, 갤럭시 등) 입력을 독립된 엑스박스 360 컨트롤러로 즉시 인식시킵니다.

철권 8, 피파(FC24), 오버쿡, 잇 테익스 투 등 스팀 로컬 협동 게임을 친구들과 모바일 폰으로 접속하여 즉시 함께 즐길 수 있습니다.
