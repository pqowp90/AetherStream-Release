Technical Deep Dive & Inquiries

Traditional streaming tools rely strictly on direct P2P socket communication. When routers use Symmetric NAT or block outbound UDP ports (common in dorms, universities, and enterprise corporate firewalls), direct hole punching fails without complex VPN configuration.

AetherStream Pro integrates 35+ global edge TURN relays that automatically step in when P2P is blocked, encapsulating low-latency UDP packets over TLS/WebSocket fallback on standard HTTPS ports (443), guaranteeing instant connectivity anywhere on Earth.

On iOS, Apple Pencil touch events are sampled at 240Hz. AetherStream encodes the 4096 pressure levels, tilt azimuth, and normalized touch coordinates into a dedicated lightweight 16-byte UDP packet (`0x20 INPUT_EVENT`).

On the Windows Host, our driver injects these inputs directly into the Windows Ink Digitizer Subsystem and Wintab API, bypassing the Windows message queue delay.

AetherStream utilizes native Windows DXGI 1.2+ Desktop Duplication APIs to access the GPU's VRAM directly without CPU memory copies. You can stream any physically attached, active display and switch between multiple monitors instantly with full hardware acceleration.
