# 주식회사 제로독 (zerodoc Inc.)
# AetherStream™ v0.1.0 공식 사용자 가이드 (Official User Manual)

AetherStream은 PC 화면을 스마트폰, 태블릿 및 원격 PC로 전송하여 눈앞의 로컬 모니터처럼 원격 플레이 및 작업을 가능하게 해주는 초저지연 리모트 스트리밍 엔진입니다.

---

## 1. 주요 핵심 기능

- **GPU VRAM 제로카피 캡처**: Windows DXGI Desktop Duplication을 통해 화면 캡처 지연 시간을 극소화합니다.
- **하드웨어 가속 인코딩**: NVIDIA NVENC 하드웨어 가속(H.264 / HEVC)을 활용하여 초저지연 압축을 수행합니다.
- **6자리 룸코드 P2P 다이렉트 통신**: 공유기 수동 포트포워딩 없이 RFC 5389 STUN 홀펀칭 기술로 다이렉트 연결을 지원합니다.
- **멀티 모니터 런타임 전환**: PC에 연결된 여러 대의 모니터를 스트리밍 도중 원클릭으로 변경할 수 있습니다.
- **4인 멀티플레이어 지원**: ViGEmBus 가상 Xbox 컨트롤러 연동을 통해 원격지 접속자들과 로컬 코옵 게임을 즐길 수 있습니다.
- **양방향 클립보드 동기화**: PC와 원격 단말 간의 복사/붙여넣기 텍스트를 실시간으로 공유합니다.
- **보안 하드닝**: ChaCha20-Poly1305 패킷 암호화, 호스트 6자리 PIN 보안 및 구글 OAuth 2.0 PKCE 인증을 지원합니다.

## 2. 호스트(Host) PC 설정 및 구동 방법

### 1단계: 프로그램 실행
1. 시작 메뉴 또는 바탕화면의 **`AetherStream`** 아이콘을 더블 클릭하여 실행합니다.
2. 프로그램이 열리면 백엔드 스트리밍 엔진(`aether-server.exe`)이 자동으로 백그라운드 기동됩니다.
3. 상단 상태 표시줄이 녹색 **`HOST ENGINE ACTIVE (상시 스트리밍 대기)`**로 표시되는지 확인합니다.

### 2단계: 룸코드 및 PIN 번호 확인
- **내 PC 룸코드**: 대시보드 중앙 상단에 큰 글씨로 표시되는 **6자리 영숫자 코드**(예: `#MZMcNp`)를 확인합니다. 이 코드를 원격지 접속자에게 알려줍니다.
- **호스트 접근 PIN**: 우측 상단 보안 패널에 표시되는 **6자리 PIN**(예: `[641425]`)을 확인합니다.
- **모니터 선택**: 다중 모니터를 사용하는 경우, 화면 하단 `디스플레이 선택` 드롭다운에서 송출을 원하는 모니터(`Monitor 1`, `Monitor 2` 등)를 선택합니다.

### 3단계: 구글 계정 보안 연동 (선택 사항)
- PIN 번호 대신 내 구글 계정으로만 접근을 허용하고 싶다면, 우측 보안 패널의 `구글 계정 연동` 버튼을 클릭하여 본인 계정을 등록할 수 있습니다.

## 3. 클라이언트(Client) 원격 접속 방법

### [방법 A] 다른 Windows PC에서 접속할 때
1. 해당 PC에서 `AetherStream`을 실행합니다.
2. 상단 탭에서 **`[ 클라이언트 모드 ]`** 버튼을 클릭합니다.
3. 호스트 PC의 **6자리 룸코드**를 입력하고 **`[ 스트림 연결 ]`**을 클릭합니다.
4. 초저지연 스트림 뷰어 창(`ClientViewerWindow`)이 열리며 호스트 PC 화면이 즉시 표시됩니다.

### [방법 B] 모바일 기기(iOS / Android)에서 접속할 때
1. 아이패드, 아이폰 또는 안드로이드 기기에서 **AetherStream** 앱을 실행합니다.
2. 화면 중앙 6자리 코드 입력란에 호스트 PC의 룸코드를 입력하고 연결을 터치합니다.
3. 애플 메탈(Metal 3) / 안드로이드 미디어코덱(MediaCodec) 하드웨어 가속을 통해 최대 120Hz/144Hz 초고주사율 화면이 전송됩니다.

## 4. 스트리밍 조작 및 단축키 안내

| 기능 | 조작키 / 방법 | 설명 |
| :--- | :--- | :--- |
| **전체화면 전환** | `F11` 키 | 스트리밍 뷰어를 전체화면 또는 창 모드로 전환합니다. |
| **세션 즉시 종료** | `Esc` 키 또는 `[ 연결 해제 ]` | 원격 세션을 안전하게 종료하고 연결을 닫습니다. |
| **모니터 실시간 변경** | 호스트 UI 드롭다운 또는 클라이언트 F-키 | 송출 중인 모니터를 즉시 다른 화면으로 전환합니다. |
| **가상 게임패드** | 모바일 화면 가상 스킨 터치 | 터치 화면의 아날로그 스틱 및 ABXY 버튼이 호스트에 게임패드로 입력됩니다. |
| **마우스 & 키보드** | 마우스 클릭/이동, 키 입력 | 호스트 OS에 즉시 하드웨어 수준으로 지연 없이 직결됩니다. |

## 5. 벤치마크 및 개발자 모드 안내

AetherStream v0.1.0은 일반 사용자의 쾌적한 원격 경험과 마우스 간섭 방지를 위해 **벤치마크 측정 코드가 상용 릴리즈 빌드에서 컴파일 타임에 원천 배제**되어 있습니다.

하드웨어 지연 시간 프로파일링이 필요한 엔지니어는 소스 트리에서 다음과 같이 명시적 피처를 활성화하여 독립 벤치마크를 수행할 수 있습니다:

```powershell
# 개발자 전용 파이프라인 벤치마크 실행 (Cargo feature로 분리)
cargo run --release --manifest-path server/Cargo.toml --features benchmark -- --benchmark
```

## 6. 자주 묻는 질문 및 문제 해결 (Troubleshooting)

### Q1. 접속 시 "UDP 소켓 바인딩 실패" 또는 "WSAEADDRINUSE" 오류가 발생합니다.
- 기존에 실행 중이던 이전 AetherStream 프로세스가 포트를 점유하고 있을 때 발생합니다.
- 작업 관리자(`Ctrl + Shift + Esc`)에서 `AetherStream.exe` 및 `aether-server.exe` 프로세스를 모두 종료한 후 다시 실행해 주십시오.

### Q2. 외부 네트워크(카페, 모바일 핫스팟 등)에서 접속이 안 됩니다.
- Windows 방화벽에서 UDP `47998` 및 `47999` 포트가 차단되었는지 확인하십시오.
- 인스톨러 설치 시 기본 옵션인 "Windows 방화벽 스트리밍 포트 자동 허용"이 체크되어 있는지 확인하십시오.

### Q3. 가상 게임패드가 인식되지 않습니다.
- 4인 로컬 코옵 가상 컨트롤러 기능을 사용하려면 시스템에 **ViGEmBus 드라이버**가 설치되어 있어야 합니다. 드라이버가 없는 경우 마우스 및 키보드 모드로 자동 폴백 동작합니다.
